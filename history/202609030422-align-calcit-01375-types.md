# Align Calcit 0.13.75 types

## Context / 背景

Copycat was pinned to Calcit 0.13.29 and older ecosystem modules. The 0.13.75
checker exposes Option, collection, nominal ReelState, Unit and typed JS FFI
contracts that the application previously crossed dynamically.

Copycat 原先固定在 Calcit 0.13.29 与较旧的生态模块；0.13.75 检查器会暴露
此前动态跨越的 Option、集合、nominal ReelState、Unit 与 typed JS FFI 契约。

## Change / 修改

- Upgrade Calcit/@calcit/procs and the released module versions.
- Preserve ReelState through nominal construction and field access.
- Replace Option-as-Bool and Set-as-List assumptions with explicit adapters.
- Centralize persisted user values at one documented Dynamic-to-Map boundary.
- Replace deprecated `tag-match` calls with `match`.
- Add the native Cirru EDN quality baseline and CI validation; mark generated
  artifacts in `.gitattributes`.
- Use unique ignored pattern names around the repeated-wildcard JavaScript
  codegen defect tracked as calcit-lang/calcit#598.

## Validation / 验证

Client/server check-only, deprecated analysis, the quality gate, server test
discovery, client/server JavaScript codegen, and the Node 24 Vite production
build pass against the current ecosystem branches.

Tracking: TopixIM/copycat#45.
